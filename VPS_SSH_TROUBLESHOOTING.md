# Решение проблем с SSH подключением к VPS

## Проблема: "No route to host" при подключении по IPv6

### Симптомы

При попытке подключения:
```bash
ssh root@2a03:6f00:a::1:a92c
```

Получаете ошибку:
```
ssh: connect to host 2a03:6f00:a::1:a92c port 22: No route to host
```

### Решение 1: Используйте квадратные скобки для IPv6

**Проблема:** IPv6 адреса в SSH должны быть в квадратных скобках.

**Неправильно:**
```bash
ssh root@2a03:6f00:a::1:a92c
```

**Правильно:**
```bash
ssh root@[2a03:6f00:a::1:a92c]
```

### Решение 2: Проверьте поддержку IPv6 на вашем компьютере

#### Mac/Linux

Проверьте, поддерживает ли ваш компьютер IPv6:

```bash
# Проверка IPv6
ping6 -c 3 2a03:6f00:a::1:a92c

# Или с квадратными скобками
ping6 -c 3 [2a03:6f00:a::1:a92c]
```

Если ping6 не работает, возможно IPv6 не настроен на вашем компьютере.

#### Windows

```powershell
# Проверка IPv6
ping -6 2a03:6f00:a::1:a92c
```

### Решение 3: Используйте веб-консоль VPS

Если SSH не работает, используйте веб-консоль прямо в панели управления:

1. **Откройте панель управления VPS**
2. **Найдите вкладку "Консоль"** (Console)
3. **Нажмите "Открыть консоль"** или "Launch Console"
4. **В браузере откроется терминал VPS**
5. **Выполняйте все команды прямо в веб-консоли**

**Преимущества:**
- Не требует SSH подключения
- Работает из любого браузера
- Не зависит от сетевых настроек вашего компьютера

### Решение 4: Найдите IPv4 адрес

Если IPv6 не работает, попробуйте найти IPv4 адрес:

1. **В панели управления VPS:**
   - Перейдите на вкладку **"Сеть"** (Network)
   - Найдите IPv4 адрес в списке интерфейсов
   - Используйте IPv4 для SSH: `ssh root@ваш-ipv4-адрес`

2. **Свяжитесь с поддержкой VPS провайдера:**
   - Запросите IPv4 адрес для вашего VPS
   - Многие провайдеры предоставляют IPv4 по запросу

### Решение 5: Проверьте настройки firewall на VPS

Возможно, порт 22 (SSH) закрыт на VPS. Проверьте через веб-консоль:

```bash
# Проверка открытых портов
sudo netstat -tuln | grep :22

# Или
sudo ss -tuln | grep :22
```

Если порт 22 не слушается, откройте его:

```bash
# Для Ubuntu/Debian
sudo ufw allow 22/tcp
sudo ufw reload

# Для CentOS/RHEL
sudo firewall-cmd --permanent --add-port=22/tcp
sudo firewall-cmd --reload
```

### Решение 6: Используйте другой порт SSH (если настроен)

Некоторые VPS провайдеры используют нестандартный порт для SSH. Проверьте в панели управления:

1. Найдите информацию о SSH подключении
2. Проверьте, указан ли другой порт (например, 2222, 22022)
3. Используйте порт в команде SSH:
   ```bash
   ssh -p 2222 root@[2a03:6f00:a::1:a92c]
   ```

## Рекомендуемый подход

**Для большинства случаев рекомендуется использовать веб-консоль VPS:**

1. Это самый простой способ
2. Не требует настройки SSH
3. Работает из любого браузера
4. Не зависит от сетевых настроек

**После настройки Ollama через веб-консоль, вы сможете использовать его из Android приложения по IPv6 адресу (для HTTP запросов IPv6 работает лучше, чем для SSH).**

## Проверка работы после настройки

После настройки Ollama через веб-консоль, проверьте доступность с вашего компьютера:

```bash
# Проверка Ollama API (HTTP работает лучше с IPv6)
curl http://[2a03:6f00:a::1:a92c]:11434/api/tags
```

Если эта команда работает - все настроено правильно, и вы можете использовать VPS в Android приложении!
