# Настройка эмулятора для полностью оффлайн работы с Ollama

## Цель

Настроить Android эмулятор для работы с Ollama (установленным на Mac) **полностью локально**, даже когда интернет полностью отключен.

## Важно

- Эмулятор должен иметь возможность достучаться до хоста через `10.0.2.2` **БЕЗ интернета**
- `10.0.2.2` - это специальный IP адрес Android эмулятора для доступа к localhost хоста
- Это локальное подключение, которое не требует интернета
- Приложение использует прямой IP без DNS запросов

## Настройка эмулятора для оффлайн работы

### Шаг 1: Настройка сети эмулятора (Android Studio)

1. **Откройте Android Studio**
2. **Tools → Device Manager**
3. **Нажмите Edit (карандаш) рядом с вашим эмулятором**
4. **Advanced Settings → Network:**
   - **Network Type:** Выберите "NAT" (Network Address Translation)
   - **DNS:** `8.8.8.8,8.8.4.4` (это для интернета, но не мешает локальному подключению)
   - **Или оставьте "Automatic"** - локальное подключение должно работать в любом случае

5. **Сохраните настройки**

### Шаг 2: Проверка локального подключения (БЕЗ интернета)

**⚠️ ВАЖНО: Отключите интернет на Mac перед проверкой!**

1. **Отключите Wi-Fi/Ethernet на Mac:**
   - System Settings → Network → Wi-Fi → Turn Off
   - Или отключите кабель Ethernet

2. **Проверьте, что интернет отключен:**
   ```bash
   ping -c 1 8.8.8.8
   # Должна быть ошибка подключения
   ```

3. **Запустите Ollama на Mac:**
   ```bash
   ollama serve
   # Оставьте терминал открытым
   ```

4. **Проверьте Ollama на Mac (локально):**
   ```bash
   curl http://localhost:11434/api/tags
   # Должен вернуть JSON с моделями (работает БЕЗ интернета)
   ```

5. **Проверьте ping до хоста из эмулятора:**
   ```bash
   adb shell ping -c 1 10.0.2.2
   # Должен работать БЕЗ интернета
   ```

6. **Проверьте доступность Ollama из эмулятора:**
   ```bash
   adb shell curl http://10.0.2.2:11434/api/tags
   # Должен вернуть JSON с моделями (работает БЕЗ интернета)
   ```

### Шаг 3: Настройка эмулятора из командной строки (альтернатива)

Если настройка через Android Studio не работает:

1. **Остановите эмулятор:**
   ```bash
   adb emu kill
   ```

2. **Найдите имя AVD:**
   ```bash
   emulator -list-avds
   ```

3. **Запустите эмулятор с настройками для локальной сети:**
   ```bash
   emulator -avd <your_avd_name> -netdelay none -netspeed full
   ```

   **Параметры:**
   - `-netdelay none` - нет задержки сети
   - `-netspeed full` - полная скорость сети
   - Эти параметры не требуют интернета, но оптимизируют локальное подключение

4. **Проверьте ping:**
   ```bash
   adb shell ping -c 1 10.0.2.2
   ```

### Шаг 4: Исправление проблемы "Network is unreachable"

Если `adb shell ping -c 1 10.0.2.2` возвращает "Network is unreachable":

1. **Запустите скрипт исправления:**
   ```bash
   ./fix-emulator-network.sh
   ```

2. **Или перезапустите эмулятор:**
   ```bash
   adb emu kill
   # Запустите заново через Android Studio или командную строку
   ```

3. **Проверьте настройки сети эмулятора:**
   - В эмуляторе: Settings → Network & Internet → Wi-Fi
   - Убедитесь, что Wi-Fi включен (даже без интернета, локальное подключение должно работать)

## Проверка полностью оффлайн работы

### Тест 1: Проверка без интернета

1. **Отключите интернет на Mac**
2. **Запустите Ollama:**
   ```bash
   ollama serve
   ```

3. **Проверьте ping:**
   ```bash
   adb shell ping -c 1 10.0.2.2
   # Должен работать
   ```

4. **Проверьте Ollama:**
   ```bash
   adb shell curl http://10.0.2.2:11434/api/tags
   # Должен вернуть JSON
   ```

5. **Запустите приложение:**
   - Включите Ollama в настройках
   - Отправьте сообщение
   - Должен работать БЕЗ интернета

### Тест 2: Проверка в приложении

1. **Отключите интернет на Mac**
2. **Запустите приложение на эмуляторе**
3. **Включите Ollama в настройках**
4. **Отправьте сообщение**
5. **Проверьте логи:**
   ```bash
   adb logcat | grep -E "OFFLINE|Ollama|10.0.2.2"
   ```
   Должны быть логи:
   - `🌐 OFFLINE MODE: Processing message with Ollama`
   - `🌐 OFFLINE MODE: Using Ollama for regular chat`
   - `✅ Resolved 10.0.2.2 to: 10.0.2.2`

6. **Проверьте ответ:**
   - Должен содержать: "🌐 OFFLINE: С Ollama (локальная модель: llama3.2:3b)"
   - Ответ генерируется локально, без интернета

## Устранение проблем

### Проблема 1: "Network is unreachable" при ping

**Решение:**
- Перезапустите эмулятор с правильными настройками сети
- См. [EMULATOR_NETWORK_10.0.2.2_FIX.md](./EMULATOR_NETWORK_10.0.2.2_FIX.md)

### Проблема 2: Ollama недоступен из эмулятора

**Решение:**
- Убедитесь, что Ollama запущен: `ollama serve`
- Проверьте, что ping работает: `adb shell ping -c 1 10.0.2.2`
- Проверьте файрвол на Mac (даже в оффлайн режиме)

### Проблема 3: Приложение не работает без интернета

**Решение:**
- Убедитесь, что Ollama включен в настройках приложения
- Проверьте логи: `adb logcat | grep -E "OFFLINE|Ollama"`
- Убедитесь, что используется `localOkHttpClient` (должно быть в логах)

## Важные замечания

1. **Локальное подключение не требует интернета:**
   - `10.0.2.2` - это специальный IP адрес эмулятора для доступа к хосту
   - Это локальное подключение через виртуальную сеть эмулятора
   - Не требует DNS запросов
   - Не требует интернета

2. **Приложение настроено для оффлайн работы:**
   - Использует `localDns` для прямого разрешения IP
   - Использует `localOkHttpClient` для локальных адресов
   - Не делает DNS запросы для `10.0.2.2`
   - Не требует интернета для работы с Ollama

3. **Ollama должен быть запущен:**
   - Даже в оффлайн режиме, Ollama должен быть запущен на Mac
   - `ollama serve` должен работать
   - Это локальный сервер, не требует интернета

## Проверка работы

После настройки проверьте:

```bash
# 1. Отключите интернет на Mac

ollama serve

# 3. Проверьте ping (должен работать БЕЗ интернета)
adb shell ping -c 1 10.0.2.2

# 4. Проверьте Ollama (должен работать БЕЗ интернета)
adb shell curl http://10.0.2.2:11434/api/tags

# 5. Запустите приложение и проверьте работу
```
