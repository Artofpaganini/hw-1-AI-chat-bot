# Настройка команды /publish

## Функционал

Команда `/publish` в чате приложения автоматически:
1. ✅ Находит последний git тег
2. ✅ Инкрементирует версию по правилам:
   - `v1.4.13` → `v1.4.14` (patch +1)
   - `v1.4.14` → `v1.4.15` (patch +1)
   - `v1.4.15` → `v1.5.0` (patch достиг 15, minor +1, patch = 0)
3. ✅ Создает новый тег
4. ✅ Пушит тег в origin
5. ✅ GitHub Actions автоматически запускает релиз

## Требования

### 1. Project Helper MCP Server должен быть запущен

```bash
cd project-helper-mcp-server
./start-server.sh
```

Сервер должен быть доступен на:
- `http://localhost:8081/mcp` (для хоста)
- `http://10.0.2.2:8081/mcp` (для Android эмулятора)

### 2. PROJECT_ROOT должен быть настроен

В `local.properties` добавьте:
```properties
PROJECT_ROOT=/Users/Victor/work/hw-1-AI-chat-bot
```

Или установите через BuildConfig (уже настроено автоматически).

### 3. Git должен быть настроен

- Репозиторий должен быть инициализирован
- Должен быть настроен remote origin
- Должны быть права на push в origin

## Использование

### В приложении:

1. Откройте приложение
2. Введите `/publish` в чате
3. Команда автоматически выполнится через MCP сервер
4. Вы увидите результат в чате

### Результат:

После выполнения команды:
- ✅ Создан новый git тег (например, `v1.4.14`)
- ✅ Тег запушен в GitHub
- ✅ GitHub Actions автоматически запустит workflow
- ✅ Будет создан GitHub Release с APK

## Логика инкремента версии

```bash
# Примеры:
v1.4.13 → v1.4.14  # patch +1
v1.4.14 → v1.4.15  # patch +1
v1.4.15 → v1.5.0   # patch достиг 15, minor +1, patch = 0
v1.5.0  → v1.5.1   # patch +1
```

**Правило:** Когда patch достигает 15, он сбрасывается в 0, а minor увеличивается на 1.

## Troubleshooting

### Ошибка: "Failed to execute command via MCP"

**Причина:** Project Helper MCP Server не запущен или недоступен.

**Решение:**
1. Запустите сервер: `cd project-helper-mcp-server && ./start-server.sh`
2. Проверьте, что сервер доступен на порту 8081
3. Убедитесь, что в приложении включен Project Helper

### Ошибка: "Command failed with exit code"

**Причина:** Проблема с git или правами доступа.

**Решение:**
1. Проверьте, что git настроен правильно
2. Убедитесь, что есть права на push в origin
3. Проверьте, что репозиторий не в detached HEAD состоянии

### Ошибка: "No existing tags found"

**Причина:** В репозитории нет тегов.

**Решение:**
- Скрипт автоматически создаст первый тег `v1.0.0`
- Или создайте тег вручную: `git tag v1.0.0 && git push origin v1.0.0`

## Альтернативный способ (вручную)

Если MCP сервер недоступен, выполните в терминале проекта:

```bash
./scripts/create-and-push-tag.sh
```

Скрипт выполнит те же действия.

## Проверка

После выполнения команды `/publish`:

1. Проверьте теги:
   ```bash
   git tag -l
   # Должен появиться новый тег
   ```

2. Проверьте GitHub Actions:
   - Перейдите: https://github.com/Artofpaganini/hw-1-AI-chat-bot/actions
   - Должен запуститься workflow "AI Release Pipeline"

3. Проверьте GitHub Release:
   - После завершения workflow появится новый Release
   - В Release будет APK и AAB
