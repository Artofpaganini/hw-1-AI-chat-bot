# Решение проблемы: Эмулятор не может достучаться до хоста (10.0.2.2)

## Проблема

При попытке подключиться к Ollama из эмулятора возникает ошибка:
```
❌ Cannot connect to Ollama server at http://10.0.2.2:11434
Connection error: Failed to connect to /10.0.2.2:11434
ENETUNREACH (Network is unreachable)
```

При проверке ping:
```bash
adb shell ping -c 1 10.0.2.2
# Ответ: Network is unreachable
```

## Причина

Проблема в сетевой конфигурации эмулятора. Эмулятор не может достучаться до хоста через специальный IP адрес `10.0.2.2`, который используется для доступа к localhost хоста.

## Решения

### Решение 1: Перезапуск эмулятора с правильными настройками сети (РЕКОМЕНДУЕТСЯ)

1. **Остановите эмулятор:**
   ```bash
   adb emu kill
   ```

2. **В Android Studio:**
   - Tools → Device Manager
   - Нажмите Edit (карандаш) рядом с вашим эмулятором
   - Advanced Settings → Network:
     - Выберите "Automatic" или "NAT"
     - DNS: `8.8.8.8,8.8.4.4`
   - Сохраните и запустите эмулятор заново

3. **Проверьте:**
   ```bash
   adb shell ping -c 1 10.0.2.2
   # Должен работать без ошибок
   ```

### Решение 2: Запуск эмулятора из командной строки с DNS

1. **Найдите имя вашего AVD:**
   ```bash
   emulator -list-avds
   ```

2. **Остановите текущий эмулятор:**
   ```bash
   adb emu kill
   ```

3. **Запустите эмулятор с правильными DNS:**
   ```bash
   emulator -avd <your_avd_name> -dns-server 8.8.8.8,8.8.4.4
   ```

4. **Проверьте:**
   ```bash
   adb shell ping -c 1 10.0.2.2
   ```

### Решение 3: Использование скрипта автоматического исправления

Запустите скрипт диагностики и исправления:
```bash
./fix-emulator-network.sh
```

Скрипт:
- Проверит текущее состояние сети
- Попытается исправить DNS настройки
- Предоставит инструкции по решению проблемы

### Решение 4: Холодный старт эмулятора (если ничего не помогает)

**⚠️ ВНИМАНИЕ: Это удалит все данные эмулятора!**

1. **Остановите эмулятор:**
   ```bash
   adb emu kill
   ```

2. **Холодный старт:**
   ```bash
   emulator -avd <your_avd_name> -wipe-data -dns-server 8.8.8.8,8.8.4.4
   ```

3. **Проверьте:**
   ```bash
   adb shell ping -c 1 10.0.2.2
   ```

### Решение 5: Проверка сетевых настроек хоста

1. **Проверьте, что localhost доступен на хосте:**
   ```bash
   curl http://localhost:11434/api/tags
   ```

2. **Проверьте файрвол на Mac:**
   - System Settings → Network → Firewall
   - Убедитесь, что Ollama разрешен или отключите файрвол временно

3. **Проверьте, что порт 11434 не занят:**
   ```bash
   lsof -i :11434
   ```

## Диагностика

### Шаг 1: Проверка эмулятора

```bash
# Проверьте, что эмулятор запущен
adb devices

# Проверьте ping до хоста
adb shell ping -c 1 10.0.2.2

# Проверьте DNS настройки
adb shell getprop net.dns1
adb shell getprop net.dns2

# Проверьте маршрутизацию
adb shell ip route
```

### Шаг 2: Проверка хоста

```bash
# Проверьте, что Ollama запущен
curl http://localhost:11434/api/tags

# Проверьте процесс Ollama
ps aux | grep ollama

# Проверьте порт
lsof -i :11434
```

### Шаг 3: Проверка подключения из эмулятора

```bash
# Проверьте доступность Ollama из эмулятора
adb shell curl http://10.0.2.2:11434/api/tags

# Проверьте с verbose выводом
adb shell curl -v http://10.0.2.2:11434/api/tags
```

## Что делать после исправления

1. **Проверьте ping:**
   ```bash
   adb shell ping -c 1 10.0.2.2
   # Должен работать
   ```

2. **Проверьте Ollama:**
   ```bash
   adb shell curl http://10.0.2.2:11434/api/tags
   # Должен вернуть JSON с моделями
   ```

3. **Запустите детальный скрипт проверки:**
   ```bash
   ./test-ollama-connection-detailed.sh
   ```

4. **Проверьте приложение:**
   - Включите Ollama в настройках приложения
   - Попробуйте отправить сообщение
   - Проверьте логи: `adb logcat | grep -E "Ollama|10.0.2.2"`

## Важные замечания

- `10.0.2.2` - это специальный IP адрес Android эмулятора для доступа к localhost хоста
- **Это локальное подключение, которое НЕ требует интернета**
- Эмулятор может работать с Ollama **полностью оффлайн**, даже когда интернет отключен
- Эта проблема не связана с приложением - это проблема сетевой конфигурации эмулятора
- После исправления сетевых настроек эмулятора, приложение должно работать корректно **БЕЗ интернета**
- Если проблема сохраняется после всех решений, попробуйте создать новый AVD

## Работа в полностью оффлайн режиме

**Важно:** Эмулятор может работать с Ollama **полностью локально**, даже когда интернет полностью отключен.

**Проверка оффлайн работы:**
1. Отключите интернет на Mac
2. Запустите Ollama: `ollama serve`
3. Проверьте ping: `adb shell ping -c 1 10.0.2.2` (должен работать БЕЗ интернета)
4. Проверьте Ollama: `adb shell curl http://10.0.2.2:11434/api/tags` (должен работать БЕЗ интернета)
5. Запустите приложение - должно работать БЕЗ интернета

См. [EMULATOR_OFFLINE_SETUP.md](./EMULATOR_OFFLINE_SETUP.md) для подробной инструкции по настройке оффлайн режима.
