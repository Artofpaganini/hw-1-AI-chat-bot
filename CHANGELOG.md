# Changelog

## [1.3.0] - 2026-01-17

### Added
В этом обновлении мы внесли значительные изменения в архитектуру приложения:

**Основные изменения:**
- Добавлена поддержка GitHub MCP сервера для расширения функциональности AI агента
- Реорганизована структура модулей: удалены модули appointments, patients, profile и settings, добавлен новый модуль project-helper-mcp-server
- Обновлены зависимости: добавлены новые библиотеки для работы с MCP серверами и улучшена поддержка DI
- Улучшена обработка ошибок в AI чате
- Оптимизирована работа с Gradle и сборкой проекта

**Технические улучшения:**
- Обновлены версии Kotlin и Compose
- Улучшена производительность за счет оптимизации зависимостей
- Добавлены новые утилиты для работы с проектами
- Улучшена поддержка разных версий Android SDK

### Breaking Changes
- Удалены модули appointments, patients, profile и settings - функциональность может быть перемещена или изменена
- Изменена структура Gradle модулей - могут потребоваться обновления в конфигурации сборки
- Обновлены версии зависимостей - возможны изменения в API совместимости

## [2.0.0] - 2026-01-17

### Added
Основные изменения:
- Добавлена интеграция с GitHub через MCP (Model Context Protocol) сервер, позволяющая AI-ассистенту взаимодействовать с репозиториями GitHub
- Удалены устаревшие MCP серверы (Google Storage, Remote Control, Weather)
- Обновлены целевые версии Android SDK для модулей appointments, patients, profile и settings до API 21
- Добавлена поддержка новых инструментов (tools) в AI чат для расширения функциональности
- Улучшена структура проекта с реорганизацией модулей
- Обновлены зависимости Gradle и конфигурация сборки
- Добавлена защита конфиденциальных данных через .env файл для GitHub MCP сервера
- Улучшена обработка ошибок и стабильность приложения

### Breaking Changes
- Удалены MCP серверы Google Storage, Remote Control и Weather - соответствующие функции больше недоступны
- Повышены минимальные требования к API для модулей appointments, patients, profile и settings до API 21
- Изменена структура проекта - могут потребоваться обновления в конфигурации сборки
