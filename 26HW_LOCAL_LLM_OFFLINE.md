**Ошибка:**
```
❌ Cannot connect to Ollama server at http://10.0.2.2:11434
Connection error: Failed to connect to /10.0.2.2:11434
Error details: ConnectException - Failed to connect to /10.0.2.2:11434
ENETUNREACH (Network is unreachable)
```

**Возможные причины:**
1. **Эмулятор не может достучаться до хоста через 10.0.2.2** - **САМАЯ ЧАСТАЯ ПРИЧИНА**
   - Ошибка: `adb shell ping -c 1 10.0.2.2` → `Network is unreachable`
   - Решение: См. [EMULATOR_NETWORK_10.0.2.2_FIX.md](./EMULATOR_NETWORK_10.0.2.2_FIX.md)

2. **Ollama не запущен на Mac** - вторая по частоте причина
3. **Проблемы с сетевыми настройками эмулятора** - неправильная конфигурация
4. **Файрвол блокирует подключение** - macOS Firewall блокирует порт 11434
5. **Ollama слушает только на localhost, а не на всех интерфейсах** - редко, но возможно

**Решение:**

**⚠️ ВАЖНО: Сначала проверьте, может ли эмулятор достучаться до хоста!**

1. **Проверьте ping до хоста (ПЕРВЫЙ ШАГ):**

   - Запустите скрипт исправления: `./fix-emulator-network.sh`

## Принцип работы (оффлайн режим)

### Архитектура оффлайн режима

```
Android App (ChatViewModel)
    ↓
OllamaApi (Retrofit) → localOkHttpClient (без DNS, прямой IP)
    ↓
10.0.2.2:11434 (прямое подключение, без интернета)
    ↓
Ollama Server на Mac (localhost:11434)
    ↓
Local LLM Models (llama3.2:3b, phi3:medium, etc.)
```

### Поток данных (оффлайн)

1. **Пользователь вводит сообщение**
2. **ChatViewModel проверяет:** `ollamaEnabled == true`
3. **Если включен Ollama:**
   - ✅ Используется `handleSendMessageWithOllama()` или `handleSendMessageWithOllamaChat()`
   - ✅ Все запросы идут через `ollamaApi.generateChat()` → `http://10.0.2.2:11434`
   - ✅ Используется `localOkHttpClient` с прямым разрешением IP (без DNS)
   - ❌ Облачные API **НЕ используются**
4. **Если выключен Ollama:**
   - Используется `handleSendMessageWithoutOllama()`
   - Запросы идут через облачные API (DeepSeek, OpenAI и т.д.)

### Ключевые особенности оффлайн режима

1. **Прямое разрешение IP:**
   - `10.0.2.2` разрешается напрямую через `InetAddress.getByName()`
   - Не требуется DNS запрос
   - Не требуется интернет

2. **Отдельный OkHttp клиент:**
   - `localOkHttpClient` используется только для локальных адресов
   - Не влияет на интернет-запросы
   - Имеет увеличенные таймауты для работы с Ollama

3. **Network Security Config:**
   - Разрешает cleartext traffic для `10.0.2.2`, `localhost`, `127.0.0.1`
   - Не требует SSL/TLS для локальных подключений
