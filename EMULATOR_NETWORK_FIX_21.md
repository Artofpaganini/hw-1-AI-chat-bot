# Решение проблем с интернетом на Android эмуляторе

## Проблема: Отсутствие интернета на эмуляторе

Если при использовании локального MCP сервера пропадает интернет на эмуляторе, выполните следующие шаги:

## Решение 1: Проверка настроек эмулятора

1. **Откройте настройки эмулятора:**
   - В Android Studio: Tools → Device Manager → Edit (карандаш) рядом с эмулятором
   - Или через командную строку: `emulator -avd <avd_name> -dns-server 8.8.8.8,8.8.4.4`

2. **Проверьте настройки сети:**
   - Settings → Network & Internet → Wi-Fi
   - Убедитесь, что Wi-Fi включен
   - Попробуйте переключить Wi-Fi выключить/включить

3. **Перезапустите эмулятор с правильными DNS:**
   ```bash
   emulator -avd <your_avd_name> -dns-server 8.8.8.8,8.8.4.4
   ```

## Решение 2: Проверка через ADB

1. **Проверьте DNS на эмуляторе:**
   ```bash
   adb shell getprop net.dns1
   adb shell getprop net.dns2
   ```

2. **Установите DNS вручную (если нужно):**
   ```bash
   adb shell "setprop net.dns1 8.8.8.8"
   adb shell "setprop net.dns2 8.8.4.4"
   ```

3. **Проверьте доступность интернета:**
   ```bash
   adb shell ping -c 3 8.8.8.8
   adb shell ping -c 3 api.deepseek.com
   ```

## Решение 3: Настройка эмулятора через AVD Manager

1. Откройте AVD Manager в Android Studio
2. Нажмите Edit (карандаш) рядом с вашим эмулятором
3. В разделе "Advanced Settings" → "Network":
   - Убедитесь, что выбрано "Automatic" или "NAT"
   - DNS: 8.8.8.8, 8.8.4.4

## Решение 4: Использование холодного старта

Иногда помогает холодный старт эмулятора:
```bash
emulator -avd <your_avd_name> -wipe-data
```

## Решение 5: Проверка файрвола и прокси

Убедитесь, что:
- Файрвол не блокирует эмулятор
- Прокси не настроен для эмулятора
- VPN не активен на хосте

## Проверка работы

После применения решений проверьте:

1. **В эмуляторе откройте браузер и попробуйте открыть любой сайт**

2. **Проверьте логи приложения:**
   ```bash
   adb logcat | grep -E "ApiClient|AiModelRepository|UnknownHostException"
   ```

3. **Проверьте, что оба подключения работают:**
   - Локальный MCP сервер: `http://10.0.2.2:8080/mcp`
   - Интернет API: `https://api.deepseek.com/`

## Важные замечания

- Локальный MCP сервер использует отдельный OkHttp клиент без DNS resolver
- Интернет API используют отдельный клиент с DNS resolver
- Оба клиента работают независимо и не должны мешать друг другу

## Если проблема сохраняется

1. Проверьте, что на хосте есть интернет
2. Перезапустите эмулятор
3. Проверьте логи приложения на наличие ошибок DNS
4. Убедитесь, что MCP серверы запущены (Weather MCP Server на порту 8080, Google Storage MCP Server на порту 8081)
