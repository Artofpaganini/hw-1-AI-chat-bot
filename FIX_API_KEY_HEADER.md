# Исправление ошибки "IllegalHeaderValueException"

## Проблема

Ошибка: `Header value '***' contains illegal character`

**Причина:** API ключ в GitHub Secrets содержит недопустимые символы (пробелы, переносы строк, табуляции).

## ✅ Исправление

### 1. Код исправлен автоматически

Код теперь автоматически очищает API ключ от:
- Пробелов
- Переносов строк (`\n`, `\r`)
- Табуляций (`\t`)
- Других недопустимых символов

### 2. Проверьте GitHub Secret

**Проблема может быть в том, как секрет сохранен в GitHub:**

1. Перейдите в **Settings** > **Secrets and variables** > **Actions**
2. Найдите секрет `DEEPSEEK_API_KEY`
3. Нажмите на него (откроется форма редактирования)
4. **Удалите секрет** (Delete secret)
5. **Создайте заново:**

**Правильный способ:**
- Скопируйте API ключ из DeepSeek платформы
- Убедитесь, что ключ НЕ содержит:
  - Пробелов в начале/конце
  - Переносов строк
  - Кавычек
  - Других символов кроме букв, цифр, `-`, `_`, `.`
- Вставьте ключ в поле **Secret**
- Нажмите **Update secret**

**Пример правильного ключа:**
```
sk-1234567890abcdefghijklmnopqrstuvwxyz
```

**Пример неправильного ключа:**
```
sk-1234567890abcdefghijklmnopqrstuvwxyz
```
(с переносом строки в конце)

или

```
  sk-1234567890abcdefghijklmnopqrstuvwxyz  
```
(с пробелами)

## 🔍 Как проверить

### Локальная проверка

```bash
# Проверьте, что ключ правильный
echo "DEEPSEEK_API_KEY" | wc -c
# Должно быть примерно 40-50 символов (без переносов строк)

# Проверьте, что нет переносов строк
echo "DEEPSEEK_API_KEY" | cat -A
# Не должно быть символов ^M или $ в конце
```

### Проверка в GitHub Actions

После исправления секрета:
1. Запустите workflow снова
2. Проверьте логи - не должно быть ошибки `IllegalHeaderValueException`
3. В логах должно быть: `API key length: XX, starts with: sk-`

## 📝 Рекомендации

1. **Всегда копируйте ключ напрямую** из источника (DeepSeek платформа)
2. **Не редактируйте ключ** вручную (не добавляйте/удаляйте символы)
3. **Проверяйте ключ** перед сохранением в GitHub Secrets
4. **Используйте "Raw" режим** при копировании (если доступно)

## 🔄 Если проблема сохраняется

1. Удалите секрет `DEEPSEEK_API_KEY` из GitHub
2. Создайте новый API ключ в DeepSeek (если возможно)
3. Скопируйте ключ БЕЗ редактирования
4. Создайте секрет заново в GitHub
5. Запустите workflow снова
