# Настройка VPS с IPv6 адресом для Ollama

## Проблема

На панели управления VPS отображается только IPv6 адрес (например: `2a03:6f00:a::1:a92c`), а не IPv4. Это нормально - многие VPS провайдеры предоставляют только IPv6 адреса.

## Решение

### 1. Использование IPv6 адреса

IPv6 адрес `2a03:6f00:a::1:a92c` - это полноценный IP адрес вашего VPS сервера. Его можно использовать для подключения к Ollama.

### 2. Формат URL для Android приложения

В настройках приложения используйте IPv6 адрес в следующем формате:

```
http://[2a03:6f00:a::1:a92c]:11434
```

**Важно:**
- IPv6 адрес должен быть в квадратных скобках `[...]`
- После скобок указывается порт через двоеточие `:11434`
- Используйте `http://` или `https://` в начале

### 3. Проверка доступности IPv6 адреса

Перед настройкой в приложении проверьте доступность сервера:

```bash
# Проверка доступности Ollama через IPv6
curl http://[2a03:6f00:a::1:a92c]:11434/api/tags
```

Если команда возвращает JSON с моделями - сервер доступен.

### 4. Настройка в Android приложении

1. Откройте приложение
2. Нажмите на иконку настроек (⚙️)
3. Прокрутите до секции "VPS Ollama Configuration"
4. Введите URL: `http://[2a03:6f00:a::1:a92c]:11434`
5. Закройте диалог настроек
6. Выберите модель "VPS - Ollama: llama3.2:3b" из выпадающего списка

### 5. Проверка IPv4 адреса (опционально)

Если нужен IPv4 адрес, проверьте другие вкладки в панели управления VPS:

- **Вкладка "Сеть"** - может содержать информацию о сетевых интерфейсах
- **Вкладка "Доступ"** - может содержать альтернативные способы подключения
- **Вкладка "Конфигурация"** - может содержать сетевые настройки

### 6. Открытие порта 11434 в firewall

На вашем VPS порт 11434 должен быть открыт. Если он в списке "Закрытые порты", нужно его открыть:

```bash
# Подключитесь к VPS по SSH
ssh root@2a03:6f00:a::1:a92c

# Для Ubuntu/Debian
sudo ufw allow 11434/tcp
sudo ufw reload

# Для CentOS/RHEL
sudo firewall-cmd --permanent --add-port=11434/tcp
sudo firewall-cmd --reload
```

### 7. Установка и запуск Ollama на VPS

```bash
# Подключитесь к VPS
ssh root@2a03:6f00:a::1:a92c

# Установите Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Запустите Ollama сервер
ollama serve

# В другом терминале установите модель
ollama pull llama3.2:3b

# Проверьте установку
ollama list
```

### 8. Проверка работы

После настройки проверьте работу:

```bash
# С локальной машины
curl http://[2a03:6f00:a::1:a92c]:11434/api/tags

# Тест чата
curl http://[2a03:6f00:a::1:a92c]:11434/api/chat -d '{
  "model": "llama3.2:3b",
  "messages": [
    {"role": "user", "content": "Hello!"}
  ],
  "stream": false
}'
```

## Важные замечания

1. **IPv6 поддержка:** Убедитесь, что ваше Android устройство и сеть поддерживают IPv6
2. **Firewall:** Порт 11434 должен быть открыт на VPS сервере
3. **Формат URL:** Всегда используйте квадратные скобки для IPv6 в URL: `http://[IPv6]:порт`
4. **Доступность:** VPS должен быть доступен из сети, где работает Android устройство

## Альтернативные решения

Если IPv6 не работает:

1. **Проверьте наличие IPv4:** Свяжитесь с поддержкой VPS провайдера для получения IPv4 адреса
2. **Используйте доменное имя:** Если доступно, настройте доменное имя для VPS
3. **VPN/Туннель:** Используйте VPN или туннель для доступа к VPS через IPv4
