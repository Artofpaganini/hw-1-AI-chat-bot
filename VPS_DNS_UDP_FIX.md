# Решение: DNS не работает - UDP порт 53 заблокирован

## Проблема

После настройки DNS видите ошибку:
```bash
nslookup ollama.com
;; UDP setup with 8.8.8.8#53(8.8.8.8) for ollama.com failed: network unreachable.
;; no servers could be reached
```

## Причина

**DNS использует UDP протокол на порту 53!**

Если вы добавили правила в firewall только для:
- TCP (для HTTP/HTTPS)
- ICMP (для ping)

Но не добавили правило для **UDP порта 53**, DNS не будет работать.

## Решение: Добавьте правило для UDP порта 53

### Шаг 1: Откройте настройки Firewall

1. **В панели управления VPS:**
   - Перейдите на вкладку **"Сеть"** (Network)
   - Найдите секцию **"Firewall"**
   - Найдите вашу группу правил (например, "Ambitious Finch")
   - Нажмите на группу правил для редактирования

### Шаг 2: Добавьте правило для UDP порта 53

1. **В секции "Исходящий трафик" (Outbound):**
   - Нажмите кнопку **"+ Добавить"** (Add)
   - Заполните поля:
     - **Адрес:** Все адреса (All addresses)
     - **Протокол:** **UDP** (не TCP!)
     - **Порт или диапазон портов:** **53**
     - **Действие:** Разрешить (Allow)
   - Сохраните правило

2. **Проверьте, что правило добавлено:**
   - В списке правил должно быть видно:
     - ICMP (для ping)
     - TCP (для HTTP/HTTPS)
     - **UDP порт 53** (для DNS) ← это должно быть!

### Шаг 3: Примените правила

1. **Примените изменения:**
   - Нажмите кнопку **"Применить"** или **"Сохранить"**
   - Дождитесь применения правил (обычно несколько секунд)

### Шаг 4: Проверьте DNS

После применения правил проверьте в веб-консоли VPS:

```bash
# Проверка DNS
nslookup ollama.com
```

**Если DNS работает:**
- Вы увидите IP адрес:
  ```
  Server:         8.8.8.8
  Address:        8.8.8.8#53
  Non-authoritative answer:
  Name:   ollama.com
  Address: 104.21.xx.xx
  ```
- **DNS настроен!** Можете устанавливать Ollama

**Если DNS все еще не работает:**
- Проверьте, что правило для UDP порта 53 сохранено и применено
- Подождите 10-20 секунд после применения правил
- Попробуйте еще раз: `nslookup ollama.com`

## Полный список необходимых правил Firewall

Для полноценной работы интернета на VPS нужны следующие правила:

### Исходящий трафик (Outbound):

1. **ICMP** - для ping
   - Протокол: ICMP
   - Порт: не требуется
   - Действие: Разрешить

2. **TCP** - для HTTP/HTTPS
   - Протокол: TCP
   - Порт: Все порты или 80, 443
   - Действие: Разрешить
   - **Важно:** Убедитесь, что поле "Порт" заполнено!

3. **UDP порт 53** - для DNS
   - Протокол: UDP
   - Порт: 53
   - Действие: Разрешить
   - **Важно:** Без этого DNS не работает!

### Входящий трафик (Inbound):

1. **TCP порт 11434** - для Ollama
   - Протокол: TCP
   - Порт: 11434
   - Действие: Разрешить

## Проверка всех компонентов

После добавления правила для UDP порта 53 проверьте:

```bash
# 1. Проверка интернета (ICMP)
ping -c 3 8.8.8.8

# 2. Проверка DNS (UDP порт 53)
nslookup ollama.com
nslookup google.com

# 3. Проверка HTTP/HTTPS (TCP)
curl -I https://www.google.com

# 4. Установка Ollama
curl -fsSL https://ollama.com/install.sh | sh
```

## Важные замечания

1. **UDP ≠ TCP:** DNS использует UDP, а не TCP. Правила для TCP не помогут DNS работать.

2. **Порт 53:** DNS всегда использует порт 53 для UDP запросов.

3. **Проверка правил:** Убедитесь, что в списке правил есть:
   - ICMP (для ping)
   - TCP (для HTTP/HTTPS)
   - **UDP порт 53** (для DNS) ← это критически важно!

4. **Применение правил:** После добавления правила обязательно нажмите "Применить" или "Сохранить".

## Альтернатива: Разрешить все UDP порты (менее безопасно)

Если хотите разрешить все UDP порты сразу:

1. **Создайте правило:**
   - **Направление:** Исходящий (Outbound)
   - **Протокол:** UDP
   - **Порт:** Все порты (All ports)
   - **Действие:** Разрешить (Allow)

2. **Сохраните и примените**

**Важно:** Это менее безопасно, но решит проблему с DNS и другими UDP сервисами.
