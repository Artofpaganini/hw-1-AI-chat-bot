# Настройка VPS Ollama в Android приложении на эмуляторе

## Важно: Разница между локальным и VPS Ollama

- **Локальный Ollama (на Mac):** Использует `http://10.0.2.2:11434` (специальный IP эмулятора для доступа к localhost хоста)
- **VPS Ollama (в интернете):** Использует публичный IP адрес напрямую: `http://109.73.194.244:11434`

**Для VPS НЕ нужно использовать `10.0.2.2`!** VPS находится в интернете, поэтому используйте его публичный IP адрес напрямую.

## Пошаговая настройка

### Шаг 1: Запустите Android приложение на эмуляторе

1. Запустите Android Studio
2. Запустите эмулятор
3. Установите и откройте приложение на эмуляторе
4. Дождитесь полной загрузки главного экрана

### Шаг 2: Откройте настройки

1. Найдите иконку **⚙️ (шестеренка)** в правом верхнем углу экрана
2. Нажмите на иконку ⚙️
3. Откроется диалоговое окно "Tools"

### Шаг 3: Найдите секцию "VPS Ollama Configuration"

1. В диалоговом окне "Tools" прокрутите список вниз
2. Найдите секцию с заголовком **"VPS Ollama Configuration"**
3. Эта секция находится после секции "Ollama Vector Search"

### Шаг 4: Введите VPS URL

1. Найдите поле ввода с подписью **"VPS Ollama URL"**
2. Нажмите на поле ввода
3. Появится клавиатура

**Введите URL вашего VPS сервера:**

**Для IPv4 адреса (публичный IP - РЕКОМЕНДУЕТСЯ):**
```
http://109.73.194.244:11434
```
(Замените `109.73.194.244` на ваш реальный публичный IPv4 адрес)

**ВАЖНО:** 
- Используйте публичный IP, а не приватный (192.168.x.x, 10.x.x.x)!
- **НЕ используйте `10.0.2.2`** - это только для локального Ollama на Mac!

**Для IPv6 адреса:**
```
http://[2a03:6f00:a::1:a92c]:11434
```
(Замените `2a03:6f00:a::1:a92c` на ваш реальный IPv6 адрес, **обязательно в квадратных скобках**)

**Для доменного имени:**
```
http://vps.example.com:11434
```
(Замените `vps.example.com` на ваш реальный домен)

### Шаг 5: Сохраните настройки

1. После ввода URL нажмите кнопку **"Close"** (Закрыть) в правом верхнем углу диалога
2. Или нажмите вне диалога для его закрытия
3. Настройки сохраняются автоматически

### Шаг 6: Выберите модель VPS Ollama

1. В верхней части главного экрана найдите выпадающий список с моделями
2. Список находится в центре верхней панели
3. Нажмите на текущую выбранную модель (например, "DeepSeek")
4. Откроется выпадающее меню со списком моделей

### Шаг 7: Выберите "VPS - Ollama: llama3.2:3b"

1. В выпадающем меню найдите модель **"VPS - Ollama: llama3.2:3b"**
2. Нажмите на эту модель
3. Меню закроется
4. В верхней панели теперь должна отображаться выбранная модель "VPS - Ollama: llama3.2:3b"

### Шаг 8: Проверьте индикатор модели

1. Рядом с названием модели есть цветной индикатор (кружок)
2. **Зеленый индикатор** = модель настроена правильно, URL работает ✅
3. **Красный индикатор** = модель не настроена, URL не введен или неверный ❌

**Если индикатор красный:**
- Вернитесь в настройки (⚙️)
- Проверьте правильность введенного URL
- Убедитесь, что используете публичный IP адрес
- Убедитесь, что порт указан: `:11434`
- Убедитесь, что IPv6 адрес в квадратных скобках: `[адрес]`

### Шаг 9: Тестирование работы

1. В нижней части экрана найдите поле ввода сообщения
2. Нажмите на поле ввода
3. Введите тестовое сообщение, например: `Привет! Как дела?`
4. Нажмите кнопку отправки (стрелка вправо или кнопка "Send")

**Должно произойти:**
- Сообщение отправится на VPS сервер
- Модель llama3.2:3b обработает запрос
- Ответ появится в чате через 5-30 секунд (зависит от скорости VPS)

## Разница между локальным и VPS Ollama

### Локальный Ollama (на Mac)

- **URL в приложении:** `http://10.0.2.2:11434`
- **Где работает:** На вашем Mac (localhost)
- **Доступ:** Только с эмулятора через специальный IP `10.0.2.2`
- **Использование:** Для разработки и тестирования

### VPS Ollama (в интернете)

- **URL в приложении:** `http://109.73.194.244:11434` (публичный IP)
- **Где работает:** На VPS сервере в интернете
- **Доступ:** Из любого места (эмулятор, реальное устройство, другой компьютер)
- **Использование:** Для продакшена и постоянной работы

## Важные замечания

1. **Публичный IP обязателен:** Для VPS используйте публичный IP адрес, а не приватный (192.168.x.x, 10.x.x.x)

2. **Не используйте 10.0.2.2 для VPS:** `10.0.2.2` - это специальный IP эмулятора для доступа к localhost хоста. Для VPS используйте публичный IP напрямую.

3. **Firewall на VPS:** Убедитесь, что на VPS открыт порт 11434 во входящих правилах firewall

4. **Ollama должен быть запущен:** На VPS сервере должен быть запущен Ollama с `OLLAMA_HOST=0.0.0.0:11434`

5. **Модель должна быть установлена:** На VPS должна быть установлена модель `llama3.2:3b` через `ollama pull llama3.2:3b`

## Устранение проблем

### Проблема: Красный индикатор модели

**Причины:**
- URL не введен
- Неверный URL
- VPS недоступен
- Firewall блокирует соединение

**Решение:**
1. Проверьте правильность URL в настройках
2. Проверьте доступность VPS: `curl http://109.73.194.244:11434/api/tags` (с вашего Mac)
3. Проверьте firewall на VPS (порт 11434 должен быть открыт)
4. Проверьте, что Ollama запущен на VPS

### Проблема: "Failed to connect" или таймаут

**Причины:**
- VPS недоступен
- Firewall блокирует соединение
- Ollama не запущен на VPS

**Решение:**
1. Проверьте доступность VPS с вашего Mac: `curl http://109.73.194.244:11434/api/tags`
2. Если не работает - проверьте настройки VPS (см. `VPS_OLLAMA_CONNECTION_FIX.md`)

### Проблема: Пустой ответ или ошибка

**Причины:**
- Модель не установлена на VPS
- Неверный modelId

**Решение:**
1. Проверьте установленные модели на VPS: `ollama list`
2. Если модель отсутствует - установите: `ollama pull llama3.2:3b`
