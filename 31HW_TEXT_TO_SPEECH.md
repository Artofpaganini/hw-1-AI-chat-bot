# Голосовой агент (Speech-to-Text) - Документация

## Промпт

Ты — старший Android-разработчик (Kotlin, Jetpack Compose), а так отлично разбираешься в работе с настройкой/работой с RAG/MCP/SYSTEM_Tools. 
Есть проект мобильного приложения Ai-Chat-Bot, может взаимодействовать с:

- со сторонними Ai(deepseek/ gpt-5 и тп)

Требование - создать функционал Голосовой агент (Speech → LLM → Text).
Соедините модуль распознавания речи с Ai-chat
Ввод: голосовая команда → распознаётся в текст → отправляется в модель → ответ возвращается текстом
Протестируйте на нескольких запросах (например: «посчитай», «дай определение», «скажи анекдот»)

Добавить на UI кнопку записи голосового сообщения (слева от кнопки отправки сообщения)
Результат: Голосовой агент с текстовым выводом 

## Что было сделано

### 1. Добавлены разрешения

В `app/src/main/AndroidManifest.xml` добавлено разрешение `RECORD_AUDIO` для доступа к микрофону:

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
```

### 2. Перемещен SpeechRecognizerManager в core:common

Класс `SpeechRecognizerManager` был перемещен из `src/main/java/com/example/aiagentchat/data/speech/` в `core/common/src/main/java/com/example/aiagentchat/data/speech/` для обеспечения доступности из всех модулей проекта.

**Основные методы:**
- `isAvailable()` - проверка доступности распознавания речи
- `startListening()` - запуск распознавания (возвращает Flow<SpeechResult>)
- `stopListening()` - остановка распознавания
- `cancel()` - отмена и очистка ресурсов

**Особенности реализации:**
- Использует Android SpeechRecognizer API для распознавания речи
- Поддерживает русский язык (ru-RU)
- Предоставляет Flow API для асинхронной работы
- Обрабатывает различные состояния распознавания (Listening, Speaking, Processing, Success, Error)
- Поддерживает частичные результаты (PartialResult) для отображения в реальном времени

### 3. Обновлен ChatUiState

В `ChatUiState` добавлены поля:
- `isListening: Boolean` - состояние записи голоса
- `speechError: String?` - ошибки распознавания речи

### 4. Добавлены события голосового ввода

В `ChatAction` добавлены действия:
- `StartVoiceInput` - начало голосового ввода
- `StopVoiceInput` - остановка голосового ввода
- `DismissSpeechError` - закрытие ошибки распознавания

В `ChatEvent` добавлены события:
- `OnStartVoiceInput` - начало голосового ввода
- `OnStopVoiceInput` - остановка голосового ввода
- `OnDismissSpeechError` - закрытие ошибки распознавания

### 5. Интеграция в ChatViewModel

В `ChatViewModel` добавлена логика обработки голосового ввода:

**Добавлены зависимости:**
- `speechRecognizerManager: SpeechRecognizerManager` - менеджер распознавания речи

**Добавлены методы:**
- `handleStartVoiceInput()` - запуск распознавания речи
- `handleStopVoiceInput()` - остановка распознавания
- `handleDismissSpeechError()` - закрытие ошибки
- `sendMessageFromVoice(text: String)` - отправка сообщения после распознавания

**Особенности реализации:**
- При старте голосового ввода запускается `SpeechRecognizerManager.startListening()`
- Результаты распознавания обрабатываются через Flow
- Частичные результаты (`PartialResult`) отображаются в поле ввода в реальном времени
- При успешном распознавании (`Success`) текст автоматически отправляется в AI-модель
- Ошибки отображаются пользователю через Snackbar
- Использование `viewModelScope` для управления корутинами
- Автоматическая очистка ресурсов в `onCleared()`
- Интеграция с существующей логикой отправки сообщений (персонализация, контекст)

**Новые параметры:**

## Принцип работы

### Архитектура

```
User Voice Input (нажатие на кнопку микрофона)
    ↓
HomeScreen (проверка разрешений)
    ↓
ChatViewModel.handleStartVoiceInput()
    ↓
SpeechRecognizerManager.startListening()
    ↓
Android SpeechRecognizer API
    ↓
SpeechResult Flow (Listening → Speaking → PartialResult → Processing → Success/Error)
    ↓
ChatViewModel (обработка результатов через Flow)
    ↓
ChatUiState (обновление UI состояния: isListening, currentInput, speechError)
    ↓
ChatInput (отображение частичных результатов в поле ввода)
    ↓
Auto-send to AI Model (при успешном распознавании - SpeechResult.Success)
    ↓
ChatViewModel.sendMessageFromVoice() (интеграция с существующей логикой отправки)
    ↓
AI Response (текстовый ответ)
    ↓
HomeScreen (отображение в чате)
```

### Поток данных

1. **Пользователь нажимает кнопку микрофона**
   - Проверяется наличие разрешения `RECORD_AUDIO` в `HomeScreen.handleVoiceInputClick()`
   - Если разрешения нет - запрашивается через `permissionLauncher`
   - Если разрешение есть - вызывается `ChatEvent.OnStartVoiceInput`

2. **ChatViewModel.handleStartVoiceInput()**
   - Проверяется доступность распознавания речи через `speechRecognizerManager.isAvailable()`
   - Обновляется состояние: `isListening = true`, `speechError = null`
   - Запускается `speechRecognizerManager.startListening()` который возвращает `Flow<SpeechResult>`

3. **SpeechRecognizerManager.startListening()**
   - Создается `SpeechRecognizer` с `RecognitionListener`
   - Настраивается Intent с языком ru-RU и поддержкой частичных результатов
   - Запускается распознавание через `startListening()`
   - Результаты передаются через Flow

4. **Обработка результатов через Flow**
   - `SpeechResult.Listening` - начало прослушивания (обновление `isListening = true`)
   - `SpeechResult.Speaking` - пользователь говорит
   - `SpeechResult.PartialResult` - частичные результаты (обновление `currentInput` в реальном времени)
   - `SpeechResult.Processing` - обработка результатов
   - `SpeechResult.Success` - успешное распознавание (текст отправляется в AI через `sendMessageFromVoice()`)
   - `SpeechResult.Error` - ошибка (отображается через Snackbar)

5. **Автоматическая отправка в AI**
   - При получении `SpeechResult.Success` вызывается `sendMessageFromVoice(result.text)`
   - Используется существующая логика отправки сообщений:
     - Сохранение сообщения пользователя в базу данных
     - Персонализация пользователя через `PersonalizeUserUseCase`
     - Построение контекста через `buildMessagesWithContext()`
     - Отправка в AI через `SendMessageUseCase`
     - Сохранение ответа AI в базу данных
     - Обновление метрик сравнения

6. **Отображение в UI**
   - Частичные результаты отображаются в поле ввода в реальном времени
   - Кнопка микрофона меняет цвет на красный и иконку на Stop во время записи
   - Поле ввода блокируется во время записи
   - Ответ от AI отображается в чате как обычное сообщение

### Обработка ошибок

- **ERROR_NO_MATCH** - "No match found" - пользователь не говорил или речь не распознана
- **ERROR_SPEECH_TIMEOUT** - "No speech input" - таймаут ожидания речи
- **ERROR_NETWORK** - "Network error" - проблемы с сетью
- **ERROR_INSUFFICIENT_PERMISSIONS** - "Insufficient permissions" - нет разрешения на запись
- **ERROR_RECOGNIZER_BUSY** - "Recognizer service is busy" - сервис занят
- **ERROR_AUDIO** - "Audio recording error" - ошибка записи аудио
- **ERROR_CLIENT** - "Client side error" - ошибка на стороне клиента
- **ERROR_SERVER** - "Server error" - ошибка сервера

Все ошибки отображаются пользователю через Snackbar в `HomeScreen`.

## Решение проблем

### Проблема: Разрешение не запрашивается

**Решение:**
- Убедитесь, что разрешение `RECORD_AUDIO` добавлено в `AndroidManifest.xml`
- Проверьте, что используется правильный `ActivityResultContracts.RequestPermission()`
- Убедитесь, что `permissionLauncher` правильно настроен в `HomeScreen`
- Проверьте версию Android SDK (для API < 23 разрешения не требуются)

### Проблема: Распознавание не работает

**Решение:**
- Проверьте, что Google Speech Services установлены на устройстве
- Убедитесь, что устройство подключено к интернету (для некоторых моделей устройств требуется интернет)
- Проверьте, что язык распознавания установлен на ru-RU в `SpeechRecognizerManager`
- Убедитесь, что микрофон работает (проверьте в других приложениях)
- Проверьте, что разрешение `RECORD_AUDIO` предоставлено в настройках приложения

### Проблема: Текст не отправляется автоматически

**Решение:**
- Проверьте логику в `sendMessageFromVoice()` в `ChatViewModel`
- Убедитесь, что `SpeechResult.Success` обрабатывается корректно
- Проверьте, что текст не пустой перед отправкой
- Проверьте логи на наличие ошибок в `SendMessageUseCase`

### Проблема: Частичные результаты не отображаются

**Решение:**
- Убедитесь, что `EXTRA_PARTIAL_RESULTS` установлен в `true` в Intent в `SpeechRecognizerManager`
- Проверьте обработку `SpeechResult.PartialResult` в `ChatViewModel`
- Убедитесь, что `ChatUiState.currentInput` обновляется при получении частичных результатов
- Проверьте, что `ChatInput` получает обновленное значение `value`

### Проблема: Приложение крашится при закрытии во время записи

**Решение:**
- Убедитесь, что в `onCleared()` вызывается `speechRecognizerManager.cancel()`
- Проверьте, что все корутины отменяются при уничтожении ViewModel
- Убедитесь, что `speechRecognitionJob` правильно отменяется в `handleStopVoiceInput()`

### Проблема: Кнопка микрофона не отображается

**Решение:**
- Проверьте, что `ChatInput` получает параметры `isListening` и `onVoiceInputClick`
- Убедитесь, что иконки `Icons.Default.Mic` и `Icons.Default.Stop` доступны
- Проверьте, что `ChatInput` правильно вызывается в `HomeScreen`

### Проблема: Компиляция не проходит

**Решение:**
- Убедитесь, что `SpeechRecognizerManager` находится в `core/common/src/main/java/com/example/aiagentchat/data/speech/`
- Проверьте, что `core/common` добавлен в зависимости `feature/chat`
- Убедитесь, что все импорты правильные в `ChatViewModel`
- Проверьте, что `androidx.core:core-ktx` добавлен в зависимости `core/common`
