# Настройка Firewall для VPS

## Проблема: VPS не имеет доступа в интернет из-за Firewall

### Симптомы

В панели управления VPS на вкладке "Сеть" → "Firewall" написано:
```
У вас еще нет созданных групп правил
```

При попытке подключиться к интернету:
```
ping -c 3 8.8.8.8
Network is unreachable
```

## Решение: Настройка Firewall

### Вариант 1: Настройка через панель управления VPS (РЕКОМЕНДУЕТСЯ)

#### Шаг 1: Откройте настройки Firewall

1. **В панели управления VPS:**
   - Перейдите на вкладку **"Сеть"** (Network)
   - Найдите секцию **"Firewall"**
   - Нажмите кнопку **"Настроить"** (Configure)

#### Шаг 2: Создайте правило для исходящих соединений

**ВАЖНО:** Это правило необходимо для доступа VPS в интернет!

**ПРОБЛЕМА:** Если вы создали правила только для TCP, ping не будет работать, так как ping использует протокол ICMP, а не TCP!

1. **Создайте новую группу правил:**
   - Нажмите "Создать группу правил" или "Add Rule Group"
   - Назовите группу: "Outbound Internet Access"

2. **Добавьте правило для ICMP (для ping):**
   - **Направление:** Исходящий (Outbound)
   - **Протокол:** ICMP (не TCP!)
   - **Порт:** НЕ УКАЗЫВАЙТЕ (ICMP не использует порты - это протокол сетевого уровня)
   - **Действие:** Разрешить (Allow)
   - **Описание:** "Разрешить ICMP для ping и проверки соединения"
   - **ВАЖНО:** 
     - ICMP не требует указания порта - оставьте поле "Порт" пустым или не заполняйте его вообще
     - Без этого правила ping не будет работать!

3. **Добавьте правило для исходящего TCP трафика:**
   - **Направление:** Исходящий (Outbound)
   - **Протокол:** TCP
   - **Порт:** Все порты (All ports) или конкретные: 80, 443, 53, или оставьте пустым для всех портов
   - **Действие:** Разрешить (Allow)
   - **Описание:** "Разрешить исходящие TCP соединения для доступа в интернет"
   - **ВАЖНО:** Убедитесь, что поле "Порт" заполнено! Если оно пустое, правило может не работать.

4. **Добавьте правило для DNS (UDP):**
   - **Направление:** Исходящий (Outbound)
   - **Протокол:** UDP (не TCP!)
   - **Порт:** 53
   - **Действие:** Разрешить (Allow)
   - **Описание:** "Разрешить DNS запросы"

5. **Сохраните группу правил**

#### Шаг 3: Создайте правило для входящих соединений на порт 22 (SSH)

**ВАЖНО:** Это правило необходимо для SSH подключения!

1. **Создайте новую группу правил:**
   - Нажмите "Создать группу правил" или "Add Rule Group"
   - Назовите группу: "Inbound SSH Access"

2. **Добавьте правило для входящего трафика:**
   - **Направление:** Входящий (Inbound)
   - **Протокол:** TCP
   - **Порт:** 22
   - **Действие:** Разрешить (Allow)
   - **Описание:** "Разрешить SSH доступ"

3. **Сохраните группу правил**

**Без этого правила SSH не будет работать! Если получаете "Operation timed out" при SSH подключении - это значит, что порт 22 заблокирован.**

#### Шаг 4: Создайте правило для входящих соединений (для Ollama)

1. **Создайте новую группу правил:**
   - Назовите группу: "Ollama Server"

2. **Добавьте правило для входящего трафика:**
   - **Направление:** Входящий (Inbound)
   - **Протокол:** TCP
   - **Порт:** 11434
   - **Действие:** Разрешить (Allow)
   - **Описание:** "Разрешить доступ к Ollama серверу"

3. **Сохраните группу правил**

#### Шаг 5: Примените правила

1. **Примените созданные правила:**
   - Нажмите "Применить" или "Save"
   - Дождитесь применения (обычно несколько секунд)

2. **Проверьте статус:**
   - В секции "Firewall" должны отображаться созданные группы правил

#### Шаг 6: Проверка работы интернета

После настройки firewall проверьте в веб-консоли VPS:

```bash
# Проверка интернета
ping -c 3 8.8.8.8
```

**Если ping работает:**
- Интернет настроен!
- Можете продолжать установку Ollama

**Если ping не работает:**
- Проверьте, что правила применены
- Попробуйте вариант 2 (настройка через консоль)

### Вариант 2: Настройка через веб-консоль VPS

Если настройка через панель не работает или недоступна:

#### Для Ubuntu/Debian

```bash
# Проверьте статус firewall
sudo ufw status

# Если firewall не активен, активируйте его
sudo ufw enable

# ВАЖНО: Разрешите исходящие соединения (для доступа в интернет!)
sudo ufw default allow outgoing

# Разрешите входящие соединения на порт 11434 (для Ollama)
sudo ufw allow 11434/tcp

# Разрешите HTTP и HTTPS (для скачивания файлов)
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Разрешите DNS (для разрешения доменных имен)
sudo ufw allow 53/udp

# Примените изменения
sudo ufw reload

# Проверьте статус
sudo ufw status verbose
```

#### Для CentOS/RHEL

```bash
# Проверьте статус firewall
sudo firewall-cmd --state

# Если firewall активен, настройте правила

# Разрешите исходящие соединения (важно!)
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --permanent --add-service=dns

# Разрешите входящие соединения на порт 11434 (для Ollama)
sudo firewall-cmd --permanent --add-port=11434/tcp

# Примените изменения
sudo firewall-cmd --reload

# Проверьте правила
sudo firewall-cmd --list-all
```

### Проверка после настройки

После настройки firewall проверьте:

```bash
# 1. Проверка интернета
ping -c 3 8.8.8.8

# 2. Проверка DNS
nslookup google.com

# 3. Проверка доступа к сайтам
curl -I https://www.google.com

# 4. Если все работает, попробуйте установить Ollama
curl -fsSL https://ollama.com/install.sh | sh
```

## Решение проблемы: Ping не работает после настройки firewall

### Проблема

Вы создали правила для TCP, но ping все еще не работает.

### Причина

**Ping использует протокол ICMP, а не TCP!** Если вы создали правила только для TCP, ping не будет работать.

### Решение

**Добавьте правило для ICMP протокола:**

1. **В панели управления VPS:**
   - Перейдите на вкладку "Сеть" → "Firewall"
   - Найдите вашу группу правил (например, "Ambitious Finch")
   - Нажмите на группу правил для редактирования

2. **Добавьте правило для ICMP:**
   - В секции "Исходящий трафик" (Outbound)
   - Нажмите "+ Добавить" (Add)
   - Заполните поля:
     - **Адрес:** Все адреса (All addresses)
     - **Протокол:** ICMP (не TCP!)
     - **Порт:** НЕ УКАЗЫВАЙТЕ (ICMP не использует порты - это протокол сетевого уровня)
     - **ВАЖНО:** ICMP не требует указания порта - оставьте поле пустым или не заполняйте его вообще
     - **Действие:** Разрешить (Allow)
   - Сохраните правило

3. **Также проверьте TCP правила:**
   - Убедитесь, что в правиле для TCP поле "Порт" заполнено
   - Если поле пустое, добавьте "Все порты" или конкретные порты: 80, 443, 53
   - Сохраните изменения

4. **Примените правила:**
   - Нажмите "Применить" или "Сохранить"
   - Дождитесь применения

5. **Проверьте ping:**
   ```bash
   ping -c 3 8.8.8.8
   ```

### Альтернатива: Разрешить все протоколы

Если хотите разрешить все протоколы сразу:

1. **Создайте правило:**
   - **Направление:** Исходящий (Outbound)
   - **Протокол:** Все протоколы (All protocols) или "Любой" (Any)
   - **Порт:** Все порты (All ports)
   - **Действие:** Разрешить (Allow)

2. **Сохраните и примените**

## Важные замечания

1. **ICMP протокол:** Обязательно разрешите ICMP для исходящего трафика - без него ping не будет работать

2. **TCP протокол:** Убедитесь, что поле "Порт" в TCP правилах заполнено! Пустое поле может означать, что правило не работает

3. **UDP протокол:** Необходим для DNS (порт 53) - разрешите исходящие UDP соединения на порт 53

4. **Порт 11434:** Этот порт нужен для работы Ollama сервера - разрешите входящие TCP соединения на этот порт

5. **HTTP/HTTPS (порты 80/443):** Необходимы для скачивания файлов - разрешите исходящие TCP соединения на эти порты

## Если ничего не помогает

1. **Свяжитесь с поддержкой VPS провайдера:**
   - Сообщите, что VPS не имеет доступа в интернет
   - Попросите проверить настройки firewall
   - Попросите включить исходящие соединения

2. **Проверьте настройки сети:**
   - Убедитесь, что сетевой интерфейс активен
   - Проверьте настройки маршрутизации
   - Проверьте, что шлюз (gateway) настроен правильно

3. **Используйте альтернативный способ установки:**
   - Загрузите Ollama вручную через панель управления VPS
   - См. инструкции в `VPS_NO_INTERNET_SOLUTION.md`
