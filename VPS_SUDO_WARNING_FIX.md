# Решение: Предупреждение sudo "unable to resolve host"

## Проблема

При выполнении команд с sudo видите предупреждение:
```
sudo: unable to resolve host 6448521-hq958575.twc1.net: Temporary failure in name resolution
nameserver 8.8.8.8
nameserver 8.8.4.4
```

## Важно: Это не ошибка!

**Предупреждение не означает, что команда не выполнилась!**

Если вы видите в выводе:
```
nameserver 8.8.8.8
nameserver 8.8.4.4
```

Это означает, что команды выполнились успешно, и DNS настройки применены!

## Почему появляется предупреждение

Sudo пытается разрешить имя хоста (hostname) для логирования команд. Если DNS не настроен или не может разрешить имя хоста, sudo выводит предупреждение, но команда все равно выполняется.

## Решение 1: Игнорировать предупреждение (рекомендуется)

Предупреждение не влияет на работу команд. Просто игнорируйте его и продолжайте работу.

## Решение 2: Убрать предупреждение (опционально)

Если предупреждение мешает, добавьте имя хоста в `/etc/hosts`:

```bash
# Добавьте имя хоста в /etc/hosts
echo "127.0.0.1 6448521-hq958575.twc1.net" | sudo tee -a /etc/hosts
```

После этого предупреждение исчезнет.

## Проверка, что DNS настроен правильно

После выполнения команд проверьте:

```bash
# Проверьте содержимое /etc/resolv.conf
cat /etc/resolv.conf
```

Должны увидеть:
```
nameserver 8.8.8.8
nameserver 8.8.4.4
```

Если видите это - DNS настроен правильно!

## Проверка работы DNS

Проверьте, что DNS работает:

```bash
# Проверка DNS
nslookup ollama.com
```

Должен вернуться IP адрес. Если работает - все настроено правильно!

## Установка Ollama

После настройки DNS попробуйте установить Ollama:

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Если все еще ошибка "Could not resolve host":**

1. **Подождите 10-20 секунд** после настройки DNS
2. **Проверьте DNS еще раз:**
   ```bash
   nslookup ollama.com
   ```
3. **Попробуйте установить Ollama снова:**
   ```bash
   curl -fsSL https://ollama.com/install.sh | sh
   ```

## Заключение

Предупреждение sudo не является ошибкой. Если вы видите `nameserver 8.8.8.8` и `nameserver 8.8.4.4` в выводе - DNS настроен правильно, и вы можете продолжать установку Ollama.
