## Как использовать эту документацию

1. **Для понимания функционала конкретной ветки**: Найдите соответствующий файл `XXHW_*.md`
2. **Для настройки и отладки**: Используйте техническую документацию в соответствующем разделе
3. **Для работы с MCP серверами**: См. документацию в разделе "Документация MCP серверов"
4. **Для истории изменений**: См. `CHANGELOG.md` и версии README из разных веток
