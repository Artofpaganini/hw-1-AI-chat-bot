# Weather MCP Server

MCP сервер для получения информации о погоде через Weather.gov API с поддержкой HTTP транспорта (JSON-RPC).

## Требования

- Java 17 или выше
- Gradle (используется из корня проекта)

## Сборка

### Создание Fat JAR (со всеми зависимостями)

```bash
cd weather-mcp-server
../gradlew :weather-mcp-server:fatJar
```

Fat JAR файл будет создан в `build/libs/weather-mcp-server-1.0.0-all.jar`

**Важно:** Используйте именно `fatJar` задачу, так как она создает JAR со всеми зависимостями, необходимыми для запуска.

**Важно:** Сервер компилируется для Java 17. Убедитесь, что у вас установлена Java 17 или выше для запуска.

## Запуск

### Использование скрипта (рекомендуется)

```bash
cd weather-mcp-server
./start-server.sh [port]
```

По умолчанию используется порт 8080, если не указан другой.

### Ручной запуск

```bash
cd weather-mcp-server
../gradlew :weather-mcp-server:fatJar
java -jar build/libs/weather-mcp-server-1.0.0-all.jar [port]
```

## Конфигурация

- **Порт по умолчанию:** 8080
- **Хост:** 0.0.0.0 (слушает на всех интерфейсах)
- **MCP endpoint:** `http://localhost:8080/mcp` (или `http://10.0.2.2:8080/mcp` для Android эмулятора)

**Важно:** URL должен заканчиваться на `/` при использовании в Android приложении, так как это базовый URL для Retrofit.

## Инструменты

### `get_weather`

Получение информации о погоде для указанного местоположения.

**Параметры:**
- `location` (обязательный, string) - Название города, адрес или координаты в формате "lat,lon" (например, "40.7128,-74.0060" или "New York")

**Возвращает:**
- Сжатую информацию о погоде (максимум 2 предложения)

**Пример использования:**
```json
{
  "name": "get_weather",
  "arguments": {
    "location": "New York"
  }
}
```

## API

Сервер использует бесплатный API от National Weather Service (NOAA) по адресу https://api.weather.gov/

**Важно:** 
- API работает только для территории США
- Для других регионов будет использован геокодинг через OpenStreetMap Nominatim, но прогноз будет доступен только если координаты находятся в США
- API не требует ключа, но требует указания User-Agent в заголовках запросов (уже настроено в коде)

## Логика работы

1. **Геокодинг:** Если `location` не является координатами, сервер использует OpenStreetMap Nominatim для получения координат
2. **Получение точки прогноза:** Сервер запрашивает точку прогноза (grid point) у Weather.gov API
3. **Получение прогноза:** Сервер запрашивает текущий прогноз для полученной точки
4. **Форматирование:** Данные форматируются в сжатый формат (максимум 2 предложения)

## Интеграция с Android приложением

1. Запустите сервер на хосте:
   ```bash
   cd weather-mcp-server
   ./start-server.sh 8080
   ```

2. Добавьте в `local.properties`:
   ```properties
   MCP_SERVER_URL=http://10.0.2.2:8080/
   ```

3. В приложении включите инструмент `get_weather` в настройках MCP Tools

4. При включенном инструменте все вопросы пользователя будут обрабатываться как поисковые запросы для получения информации о погоде

## Проверка работоспособности

```bash
curl -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "get_weather",
      "arguments": {
        "location": "New York"
      }
    }
  }'
```

## Troubleshooting

### Сервер не запускается

- Убедитесь, что порт 8080 не занят другим процессом
- Проверьте, что Java 17+ установлена: `java -version`
- Проверьте логи в консоли

### Ошибки геокодинга

- Убедитесь, что у вас есть интернет-соединение
- Проверьте, что OpenStreetMap Nominatim доступен
- Для координат используйте формат "lat,lon" (например, "40.7128,-74.0060")

### Ошибки Weather.gov API

- API работает только для территории США
- Убедитесь, что координаты находятся в США
- Проверьте логи сервера для деталей ошибки
