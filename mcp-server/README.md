# MCP Weather Server

MCP сервер для получения информации о погоде через OpenWeatherMap API с поддержкой HTTP транспорта (JSON-RPC).

## Требования

- Java 17 или выше
- Gradle (используется из корня проекта)

## Сборка

```bash
cd mcp-server
../gradlew build
```

JAR файл будет создан в `build/libs/mcp-server-1.0.0.jar`

**Важно:** Сервер компилируется для Java 17. Убедитесь, что у вас установлена Java 17 или выше для запуска.

## Запуск HTTP сервера

Сервер использует HTTP транспорт с SSE (Server-Sent Events) для коммуникации:

```bash
cd mcp-server
java -jar build/libs/mcp-server-1.0.0.jar [port]
```

По умолчанию сервер запускается на порту 8080 и слушает на всех интерфейсах (0.0.0.0).

MCP endpoint доступен по адресу: `http://localhost:8080/mcp` (или `http://10.0.2.2:8080/mcp` для Android эмулятора)

**Важно:** Убедитесь, что вы пересобрали JAR файл после изменений:
```bash
../gradlew build
```

## Использование Weather.gov API

Сервер использует бесплатный API от National Weather Service (NOAA) по адресу https://api.weather.gov/

**Важно:** API работает только для территории США. Для других регионов будет использован геокодинг через OpenStreetMap Nominatim, но прогноз будет доступен только если координаты находятся в США.

API не требует ключа, но требует указания User-Agent в заголовках запросов (уже настроено в коде).

## Запуск на эмуляторе Android

Для запуска на Android эмуляторе:

1. Запустите MCP сервер на хосте:
```bash
cd mcp-server
java -jar build/libs/mcp-server-1.0.0.jar 8080
```

2. В Android приложении используйте URL: `http://10.0.2.2:8080/mcp`

3. Добавьте в `local.properties`:
```
MCP_SERVER_URL=http://10.0.2.2:8080/
```

**Важно:** URL должен заканчиваться на `/`, так как это базовый URL для Retrofit.

## Интеграция с Cursor (Tools & MCP)

Для добавления сервера в Cursor, добавьте следующую конфигурацию в `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "my-mcp-server": {
      "command": "java",
      "args": [
        "-jar",
        "/absolute/path/to/mcp-server/build/libs/mcp-server-1.0.0.jar"
      ],
    }
  }
}
```

Замените `/absolute/path/to/mcp-server` на абсолютный путь к директории mcp-server в вашем проекте.

## Инструменты

Сервер предоставляет следующий инструмент:

- `get_weather` - Получение информации о погоде для указанного местоположения
  - Параметры:
    - `location` (обязательный) - Название города, адрес или координаты в формате "lat,lon" (например, "40.7128,-74.0060" или "New York")
  - Возвращает: сжатую информацию о погоде (максимум 2 предложения)
  - Использует API: https://api.weather.gov/ (бесплатный, без ключа, работает для США)

## Интеграция с Android приложением

При включенном инструменте `get_weather` в чате, все вопросы пользователя будут обрабатываться как поисковые запросы для получения информации о погоде.

Данные о погоде фильтруются через AI чат и отображаются в сжатом виде (максимум 2 предложения).
