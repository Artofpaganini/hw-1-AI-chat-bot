# Исправление: Ollama возвращает пустой список моделей

## Текущая ситуация

✅ **Ollama доступен извне:** `curl http://109.73.194.244:11434/api/tags` работает
❌ **Пустой список моделей:** Возвращается `{"models":[]}`

## Причина

**Модель `llama3.2:3b` еще не установлена на VPS сервере!**

Ollama работает правильно, но в нем нет установленных моделей.

## Решение: Установите модель llama3.2:3b

### Шаг 1: Убедитесь, что Ollama запущен

**В веб-консоли VPS выполните:**

```bash
# Проверьте, запущен ли Ollama
ps aux | grep ollama | grep -v grep
```

**Если процесс не найден:**
- Запустите Ollama: `OLLAMA_HOST=0.0.0.0:11434 ollama serve`
- Оставьте этот терминал открытым

**Если процесс найден:**
- Продолжайте к Шагу 2

### Шаг 2: Откройте второй терминал для установки модели

**ВАЖНО:** Не закрывайте терминал, где запущен `ollama serve`!

**В веб-консоли VPS:**
- Откройте новую вкладку терминала (если доступно)
- Или используйте другой способ подключения к VPS

### Шаг 3: Установите модель llama3.2:3b

**Во втором терминале веб-консоли VPS выполните:**

```bash
ollama pull llama3.2:3b
```

**Что происходит:**
- Скачивается модель llama3.2:3b (размер ~2GB)
- Процесс займет 5-15 минут в зависимости от скорости интернета
- Вы увидите прогресс загрузки

**Пример вывода:**
```
pulling manifest
pulling 2a03:6f00:a::1:a92c... 100%
pulling manifest
pulling 2a03:6f00:a::1:a92c... 100%
verifying sha256 digest
writing manifest
success
```

### Шаг 4: Проверьте установку модели

**После завершения установки выполните:**

```bash
ollama list
```

**Должен вывестись список моделей, включая:**
```
NAME            ID              SIZE    MODIFIED
llama3.2:3b     abc123def456    2.0 GB  2 minutes ago
```

### Шаг 5: Проверьте доступность модели через API

**С вашего Mac выполните:**

```bash
curl http://109.73.194.244:11434/api/tags
```

**Должен вернуться JSON с моделью:**
```json
{
  "models": [
    {
      "name": "llama3.2:3b",
      "modified_at": "2024-01-20T12:00:00Z",
      "size": 2147483648
    }
  ]
}
```

### Шаг 6: Тест чата (опционально)

**С вашего Mac выполните:**

```bash
curl http://109.73.194.244:11434/api/chat -d '{
  "model": "llama3.2:3b",
  "messages": [
    {"role": "user", "content": "Hello!"}
  ],
  "stream": false
}'
```

**Должен вернуться ответ от модели.**

## Если установка модели не работает

### Проблема 1: "Failed to connect to ollama.com"

**Причина:** Проблемы с интернетом или DNS.

**Решение:**
```bash
# Проверьте интернет
ping -c 3 8.8.8.8

# Проверьте DNS
nslookup ollama.com

# Если DNS не работает, настройте DNS (см. VPS_DNS_SETUP.md)
```

### Проблема 2: "Network is unreachable"

**Причина:** Firewall блокирует исходящие соединения.

**Решение:**
- Проверьте firewall правила для исходящего трафика
- Убедитесь, что есть правила для TCP (порты 80, 443) и UDP (порт 53)
- См. `VPS_FIREWALL_SETUP.md`

### Проблема 3: Медленная загрузка

**Причина:** Модель большая (~2GB), загрузка может занять время.

**Решение:**
- Подождите завершения загрузки
- Проверьте скорость интернета: `curl -o /dev/null -s -w "%{speed_download}\n" https://ollama.com`

## Важные замечания

1. **Ollama должен быть запущен:** Модель устанавливается через Ollama, поэтому Ollama должен быть запущен.

2. **Два терминала:** Один терминал для `ollama serve`, другой для команд установки модели.

3. **Размер модели:** Модель llama3.2:3b весит ~2GB, загрузка может занять время.

4. **Интернет:** Для установки модели нужен доступ в интернет (ping, DNS, HTTP/HTTPS).

## Заключение

После установки модели `llama3.2:3b` через `ollama pull llama3.2:3b`, API должен вернуть список с моделью вместо пустого массива.
